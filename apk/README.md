# Jadwale Android APK

Berkas instalasi aplikasi Android Jadwale versi debug.

- **Nama Berkas**: `jadwale-app-debug.apk`
- **Ukuran**: ~18.8 MB
- **Fitur Utama**:
  - Manajemen Jadwal & Generator CSP
  - Dashboard Multi-Role (Superadmin, Admin Sekolah, Guru, Orang Tua/Umum)
  - Logo Adaptif Brand Jadwale
  - Manajemen Guru (CRUD + Matriks Hari Mengajar)
  - Manajemen Rombel/Kelas (CRUD)
  - Cetak & Ekspor Dokumen Resmi Jadwal
